# AE2LT Packaged Pattern Provider 1.2.4-beta2

Minecraft 1.21.1 · NeoForge · Beta

对比版本：`1.2.4-beta`

## 中文

- 更新至 AE2 Lightning Tech `2.1.4-beta2` 的共享供应器面板兼容修复，处理与 AppliedFlux 同装时打开界面可能因 `Duplicate id: upgrades` 断开连接的问题。
- 为普通、无线、扩展三种封包供应器登记 AppliedFlux 感应卡，每台允许安装一张。封包核心保留独立槽位，不与感应卡槽混用。
- 补充三种封包和两种超载供应器的界面回归场景，检查重复升级栏／工具箱、分页、窗口缩放、感应卡准入及核心槽隔离。

依赖：AE2 Lightning Tech `2.1.4-beta2` 或更新版本、Thunderbolt Core `2.0.3`。AppliedFlux 仍是可选模组。

验证范围：有／无 AppliedFlux 两组完整单元测试均通过；构建与界面测试代码编译通过。实际整合包中的游戏内界面回归尚未完成。

## English

- Requires AE2 Lightning Tech `2.1.4-beta2`, which handles repeated shared provider panels and the `Duplicate id: upgrades` screen-opening failure when used with AppliedFlux.
- Register AppliedFlux's Induction Card for normal, wireless and extended packaged providers, with a limit of one per provider. Packaged cores retain their separate slot.
- Expanded screen regression scenarios to cover three packaged and two overloaded provider variants, repeated upgrade/toolbox registration, paging, resizing, induction-card admission and core-slot separation.

Requires AE2 Lightning Tech `2.1.4-beta2` or newer and Thunderbolt Core `2.0.3`. AppliedFlux remains optional.

Validation: the complete unit suite passed with and without AppliedFlux. Builds and screen-test source compilation also passed. In-game screen regression in the reported modpack has not yet been completed.
