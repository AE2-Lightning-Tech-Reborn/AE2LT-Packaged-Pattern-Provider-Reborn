# Clibano

使用炽炉封包核心自动派发 Clibano 的燃烧配方。燃料、灵魂火焰类型和残渣由原炽炉处理；封包核心只负责输入与输出归属。

派发前会检查配方要求的火焰等级。当前火焰或灵魂槽里的材料满足要求时才投入原料；火焰等级不足时请补充对应的灵魂材料。燃料仍需另外供给。

合成原料全部消耗后，只回收样板承诺的产物数量。残渣合成等来源增加的同类产物会留在输出槽；请另行取出，清空输出槽后才能继续派发。
