# Nature's Aura

The Nature Altar, Tree Ritual and Offering Table each use their own Packaged Core.
Processing runs on the complete native structure, with the original Aura cost and timing.

Tree patterns include the stand ingredients, one sapling and any missing Gold Powder.
Connect the provider to a Wooden Stand. Offering patterns include the table input and
one activation item. Encode only the recipe product as output; incidental drops remain in the world.

On cancellation, only unconsumed items still held by the structure are returned.
