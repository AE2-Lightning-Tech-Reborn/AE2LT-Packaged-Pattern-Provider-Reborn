# Nature's Aura

These three packaged cores automate physical machines. Encode the quantities for **one craft** in a processing pattern. Machines retain their native processing time and resource costs. Install the corresponding core, connect or wirelessly bind the target, and enable **automatic return** on the provider. With automatic return off, completed products remain saved in the machine until it is re-enabled; breaking the machine drops those products.

## Natural Altar

<ItemLink id="ae2ltpp:naturesaura_altar_packaged_core" />

Bind the Natural Altar. The pattern contains the consumed ingredient and the exact result. Build the altar structure, supply Aura, and place any required catalyst blocks in their native positions. Catalysts stay in the world and do not belong in the pattern. Insufficient Aura leaves the craft waiting in the altar.

## Ritual of the Forest

<ItemLink id="ae2ltpp:naturesaura_tree_ritual_packaged_core" />

Bind **any Wood Stand** belonging to the ritual. Arrange enough stands at the native ritual positions; the layout must identify one unambiguous center. A complete ring of eight stands works even with no Gold Powder placed yet. Nearby overlapping layouts that cannot identify one center cannot dispatch.

Inputs are all ritual ingredients, **one matching sapling**, and the Gold Powder needed to fill the ring. Outputs contain only the exact ritual result.

* All 16 powder positions already filled: omit powder from the pattern.
* All 16 positions empty: include 16 Gold Powder.
* Partially filled ring: include exactly the missing number of Gold Powder.

The provider fills only empty powder positions, distributes ingredients over empty stands, and plants the sapling on suitable soil. The center must initially be empty. Wait for natural growth or use a separate bone-meal setup; the core does not create a free tree. The native ritual consumes its ingredients, tree and all 16 Gold Powder. Existing powder is therefore a resource for this craft, not a reusable catalyst. Patterns omitting powder need external replenishment for subsequent crafts.

Keep the ritual structure intact while it runs. Native cancellation after consumption cannot refund the consumed ingredients.

## Offering Table

<ItemLink id="ae2ltpp:naturesaura_offering_packaged_core" />

Bind the Offering Table, build its flower arrangement, and encode the offered ingredient **plus one Calling Spirit (or the recipe's actual start item)**. The output is the exact native recipe result. The table must be empty when dispatching.

The core immediately triggers the native table using the paid start item without spawning it in the world. Magnets, collectors and dropped-item cleanup cannot take it, and nearby manual start items are left alone. Results, including native Wither Rose bonus drops, return automatically instead of falling from the sky. It never collects unrelated dropped items.

## Obtaining the cores

Process a Basic Packaged Core in the corresponding native machine. The altar recipe consumes Aura; the forest recipe also requires Gold Leaf and Token of Joy; the offering recipe uses a Calling Spirit. These recipes are available only when Nature's Aura is installed.
