# Black Hole

Install the <ItemLink id="ae2ltpp:forbidden_arcanus_black_hole_packaged_core" /> and target an actual Forbidden Arcanus Black Hole. Encode 1,200 mB of a fluid in `forge:experience` as input and one XPetrified Orb as output. This conversion consumes the ME fluid and returns the orb without changing the black hole's native XP counter. The amount and fluid tag can be changed with the `ae2ltpp:fa_black_hole` datapack recipe.
