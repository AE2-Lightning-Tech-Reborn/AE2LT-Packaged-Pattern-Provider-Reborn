# Maid Altar

<ItemLink id="ae2ltpp:maid_altar_packaged_core" />

Connect a formed six-pillar maid altar. Item recipes use native altar matching and P costs. Entity summoning, rebirth and lightning rituals are excluded.

P is a separate ME resource: 100 raw units = 1 P. Annihilation planes absorb native P entities; processing one power-point item at the altar yields **0.6 P**. A storage bus on a native maid beacon's upper block provides P storage; import and export buses also work.

JEI includes real P ingredients. The first core uses a basic core, five materials and 1 P at the altar.
