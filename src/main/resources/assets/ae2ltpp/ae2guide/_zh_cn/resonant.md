# 谐振布局

基础封包核心与水晶科技的谐振样板供应器可合成 <ItemLink id="ae2ltpp:resonant_packaged_core" />。
核心记录一套机器的相对输入位置，通过机器原生物品栏和流体等接口投料。
配方执行、加工时间和机器自身耗能仍由机器负责。

1. 手持核心，对机器主方块右键，选定**原始锚点**。
2. 潜行滚轮选择输入栏位，然后右键对应输入口的面。再次点击同一面可清除绑定。
   支持 144 个输入栏位，编号对应处理样板原始网格，空栏位和重复材料都保留各自编号。
3. 子输入口到主方块的直线距离默认最多 32 格，可在服务端配置 `resonantInputRange` 中调整。
   对空气右键查看当前输入栏位。新布局开启自动回收后，只从当前主方块的连接面提取样板产物。
   已有子输出口绑定仍按原布局回收；不再提供新建或修改子输出口的操作。
4. 将核心装入封包供应器。普通封包使用输出方向上相邻的同类主方块；无线封包用无线连接器
   绑定各套机器的锚点。锚点方块种类须与原始锚点相同，一次配方的所有原料会发送到同一套机器。

**普通处理样板**按核心的栏位绑定投料；未绑定的原料送到锚点最初点击的面。
此核心不处理工作台合成样板。

**水晶科技谐振样板**优先采用样板自身的原料目标：将其绝对位置减去核心保存的原始锚点，
得到相对位置，再应用到当前机器。未标记目标的原料采用核心默认配置。
所有显式目标必须在原始锚点所在维度。应当在样板最初标记的那套布局中选定原始锚点，
不能随意选择另一个位置来解释旧样板。绑定完成后，原始机器可以拆除，也无需保持加载。

坐标偏移和输入、输出面会随锚点朝向一起水平旋转。没有水平朝向的方块以点击/连接的水平面
作为方向；点击竖直面时以北为参考。复制布局时从对应面绑定，整套布局使用当前锚点的维度。

手持另一个谐振核心右键已配置的封包供应器，可复制布局及原始参照。潜行右键机器会重新选定
锚点并清空已有绑定。核心在供应器之间移动时保留配置。目标区块未加载时等待，不会强制加载。

接受配方前检查全部端口。若机器随后只接收了部分原料，供应器会保存余料及其原始目标、输入面，
继续补发；重载或更换核心不会改投新布局。余料补发完成前暂停新配方，破坏供应器只掉落尚未投出的
材料。目标被换成不同种类的方块时，暂停向该位置补发。
