# 烹饪锅

<ItemLink id="ae2ltpp:fd_cooking_pot_packaged_core" />
<ItemLink id="ae2ltpp:ad_extreme_cooking_pot_packaged_core" />

连接农夫乐事烹饪锅或无尽乐事终极烹饪锅，锅下方保留有效热源，并将供应器回收模式设为 **自动回收**。终极烹饪锅核心向下兼容普通锅。

将一份原生配方编码为处理样板。配方需要碗、瓶等容器时，除食材外，**每份成品还要输入一个餐具**；一次产出两份食物就输入两个碗。材料种类较多时使用过载样板。

供应器将重复食材分配到不同配方槽，餐具送入餐具槽，等待原生烹饪完成后只回收成品槽。锅内全部清空才会开始下一份配方，避免串料。已有食材、餐具或待盛装食物会阻止新投料，接入前请清空；同一口锅不要再接其他输入管道。

普通核心由基础核心和四种材料烹饪得到。终极核心消耗普通核心升级，JEI 同时提供原生制造和供应器原位升级配方。制作核心不需要碗或瓶子。

牛奶桶等原生食材余物仍按模组原规则弹出锅旁，可用漏斗或收集设备回收。封包不会把锅内未盛装的食物直接取走。保留热源、原生配方优先级、加工时间和余物规则。复用这两种烹饪配方类型的数据包和附属无需额外核心；使用独立机器的附属需另行适配。
