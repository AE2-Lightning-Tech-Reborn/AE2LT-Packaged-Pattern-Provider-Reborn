# 仪式火盆

**所需封包核心：** <ItemLink id="ae2ltpp:ars_ritual_brazier_packaged_core" />
**来源模组：** Ars Nouveau（新生魔艺）

把供应器贴着仪式火盆放置，开启自动返回。处理样板按一次仪式填写：**恰好一张仪式石板，加上原生仪式认可的增强材料**。输入逐件通过仪式的接收规则和启动条件校验，包括物品组件、重复数量限制；每张样板最多 4,096 件输入，不接受流体和多张石板。

供应器会装入石板，通过火盆原生接口逐件投入材料，然后启动仪式。火盆必须空闲且没有红石暂停信号；已有待启动或运行中的仪式不会被替换。魔源、耗时、红石暂停、仪式中继和世界效果继续由原模组处理，请准备对应魔源和环境。

**返回不限样板输出**：封包启动的仪式直接生成的物品都会返回，未填写的副产物也能回收。附近手动丢下的物品、手动启动仪式的产物不会被收走。仪式进度和已收集产物随火盆存档；拆除火盆会掉出缓存产物。返回关闭或堵塞后，缓存满时后续产物按原版方式掉落到世界。

例如：启蒙石板 ×1 ＋ 书与笔 ×2 → 书龙护符 ×2。样板应填写实际期望的产物，让 AE2 能够完成订单。输出栏不会凭空生成物品；召唤或环境仪式可能没有物品产出，填写了不会生成的物品，AE2 订单会一直等待。原生仪式直接送入相邻容器的物品，以及稍后由独立投射物或实体生成的物品，仍走原生收集路线。

本核心在附魔装置中制作：基础封包核心作试剂，基座放仪式火盆 ×1、魔源宝石 ×3，消耗 1,000 魔源。
