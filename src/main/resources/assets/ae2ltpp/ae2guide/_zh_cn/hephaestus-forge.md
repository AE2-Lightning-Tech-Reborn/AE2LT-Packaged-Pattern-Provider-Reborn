# 赫菲斯托斯锻造熔炉

支持生成物品的仪式：一个主材料，最多八个基座材料。必须建造完整底座并放置八个空基座。

精华和增强器需要另行准备，封包核心不会生成这些资源。除等级升级以外的其他非物品结果仪式不自动化。

升级仪式同样支持自动化。请使用创造模式物品栏中对应等级（2–5 级）的「赫菲斯托斯锻造熔炉升级凭证」作为加工样板的唯一输出。凭证是本附属模组在熔炉实际升级成功后提供的完成证明，并非 Forbidden Arcanus 产生的物品；每次成功升级仅结算一次。升级后的熔炉仍保留在原位。

每次派发只执行一个仪式。仪式完成后，仅回收本次派发记录的预期产物；加工中或手动放入的物品不会主动回收。

请勿在仪式执行期间拆除结构、取走材料或让其他设备写入同一台熔炉。仪式失败遵循原模组规则，不会凭空补偿材料或精华。
