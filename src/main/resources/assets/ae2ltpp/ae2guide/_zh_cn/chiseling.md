# 凿子与装饰方块

在合成栏中用基础封包核心和对应模组的凿子合成专用核心，装入普通或无线封包样板供应器。
编码**处理样板**：一种原料 → 指定装饰变体。样板只需放转换原料，不需要反复提供凿子。

* **Chipped 5.x**：使用统一的凿子封包核心，供应器贴住完整工作台的可见主体，
  或把无线目标绑定到主体。七种工作台均可；这个版本的工作台共用转换配方。
  拆掉任意一半都会停止合成，不会操作玩家背包。
* **Rechiseled**：使用同一个凿子封包核心，无需工作台或无线目标。
  支持 1.2 配方接口，包含连接纹理变体及已注册的附属配方。
  1.2 的方块与半砖按实际数量比例编码；一次转换必须用完声明的原料，不能留下余料。
* **Chisel Reborn**：使用同一个凿子封包核心，无需工作台或无线目标。
  Reborn 的凿子可制作核心。
  仅允许在当前模组真实注册的雕刻分组内按 1:1 转换。

数量和产物组件必须符合真实转换。多余材料、无关变体、伪造产物组件和虚增产量都会被拒绝。
样板可以写多份材料的转换，仍按封包原有规则耗电和限制批量。
