# 雕刻

将基础封包核心与支持的凿子或任意 Chipped 工作台无序合成，得到雕刻封包核心。将其安装到普通或无线封包样板供应器，
编码“原材料 → 目标变体”的处理样板。核心提供工具，样板只需要填写待转换的材料。

Rechiseled 转换在供应器内部完成，无需工作台或无线目标。方块与台阶等转换必须按原生比例编码，
且完整消耗声明的原料，不允许余料。无关变体、虚构产物 NBT 和夸大的数量会被拒绝。

Chipped 3.x 需要完整工作台。将供应器贴在工作台主半块，或将无线供应器连接到主半块。
各工作台使用各自的原生配方类型，只能按 1:1 转换该工作台提供的变体。拆除任意半块都会停止合成。
供应器不会访问玩家背包。

转换范围由已安装模组的实时配方决定，包含附加模组注册的配方。适用普通能耗和每刻派发限制。

关闭阻塞模式及合成锁定时，Chipped 和内部雕刻可按同一具体输入批量转换；每条通道每 tick 共用最多 64 次额度。
